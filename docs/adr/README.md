# Architecture Decision Records

One file per decision that is **hard to reverse**. Not every choice — a decision earns an ADR when
undoing it later would mean rewriting code that other code depends on, or migrating data.

Naming: `NNNN-short-kebab-title.md`, numbered in the order decided.

Each record carries: **Context** (what forced the decision), **Decision** (what we chose, in one
sentence), **Consequences** (what this now makes easy, and what it makes expensive), and **Status**
(`accepted` · `superseded by NNNN`). A superseded record is never deleted — the reasoning is the
point, and a decision that was later reversed is the most useful record in the directory.
